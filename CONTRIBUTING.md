# Contributing to Bank Management System

Thank you for your interest in contributing to this educational Java Swing & JDBC project!

## Development Workflow

1. **Fork the Repository**: Create your own fork on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Commit Standards**: Follow [Conventional Commits](https://www.conventionalcommits.org/):
   - `feat: add new customer search filter`
   - `fix: resolve unclosed JDBC statement in BankDAO`
   - `docs: update environment variable installation steps`
   - `test: add unit test for customer initialization`
4. **Code Quality & Testing**:
   - Ensure all code builds cleanly: `mvn clean test`
   - Maintain Java 17 compatibility.
5. **Open a Pull Request**: Submit a clear PR describing your changes.
