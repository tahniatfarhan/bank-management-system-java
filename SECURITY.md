# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority. If you discover a vulnerability or security issue within this project (such as hardcoded secrets, unsafe SQL queries, or resource leaks), please follow responsible disclosure practices:

1. **Do NOT open a public GitHub issue.**
2. Send an email to **tahniatfarhan@gmail.com** or contact the repository owner directly.
3. Include details on the vulnerability, steps to reproduce, and potential impact.

We will acknowledge receipt within 48 hours and work on a prompt remediation release.
